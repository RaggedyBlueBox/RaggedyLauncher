# UI Design

## Direction

The visual style is original: calm, bright, and readable on a TV.

- Deep indigo background.
- Soft blue and mint accents.
- Large rounded cards.
- Strong focus rings for controller use.
- Clear separation between tabs, lists, actions, and status.
- Minimal motion with fast transitions.

## Version screen

The modpack choice is a horizontal row at the top.

- Left tab: Simply Legacy.
- Right tab: Re-Console.
- Left and right switch tabs only.
- Down moves focus into the version list.
- Up at the top of the version list returns to the tabs.
- Up and down scroll versions while the list has focus.
- A confirms the focused item.
- B returns.

## Login screen

The login screen is an original device-code experience.

- Large code display.
- Clear verification URL.
- Copy button.
- Waiting state with retry and back actions.
- No password field.
- No third-party login UI copied.

## Feedback

Every screen shows what is selected, what will happen next, and how to return. Status text uses plain language. Errors explain the failed step and the next action.
