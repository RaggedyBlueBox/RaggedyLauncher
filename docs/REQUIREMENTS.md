# Requirements

## Product

A controller-first Minecraft Java launcher for Xbox Series S|X in Developer Mode and Windows.

## Required behavior

- Official Microsoft device-code sign-in.
- Minecraft Java entitlement verification before game downloads.
- Separate profiles with version, loader, mods, worlds, and settings.
- Local target catalog.
- Horizontal modpack tabs.
- Separate vertical version list.
- Downloads start on Play.
- Fabric, Forge, NeoForge, and vanilla targets where supported.
- Modrinth browsing and optional CurseForge support.
- Controller-first menu navigation.
- Original visual design.
- Optional local file tools.
- Crash details and opt-in diagnostics.
- MIT license for original work.

## Hard limits

- No authentication bypass.
- No offline or cracked account support.
- No bundled Minecraft files.
- No copied source, UI, assets, strings, schemas, scripts, or manifests.
- No claim of endorsement by Microsoft, Xbox, Mojang, Minecraft, or third-party projects.

## Foundation acceptance criteria

- MIT license present.
- Provenance rules present.
- Architecture present.
- Core target filtering compiles.
- Core launch plan validation compiles.
- Core tests pass.
